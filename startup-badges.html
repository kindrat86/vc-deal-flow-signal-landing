❓ FAQ

How do I embed a badge in my GitHub README?

Add this to your README.md, replacing STARTUP-SLUG with your startup's slug:
![VC Deal Flow Signal](https://gitdealflow.com/api/badge/startup/STARTUP-SLUG)

Is this free?

Yes, completely free. No registration, API key, or rate limits. Cached on our CDN for fast global loading.

How often is data refreshed?

The signals dataset is updated weekly. Badges are CDN-cached up to 24 hours between refreshes.

My startup isn't listed. Can I get a badge?

Yes! If a slug isn't found, the API returns a "Create Your Own Badge" linking to gitdealflow.com/check-velocity.
