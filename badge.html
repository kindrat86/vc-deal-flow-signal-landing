API Reference

Endpoint

GET https://gitdealflow.com/api/badge/stats

Response Headers

// Content negotiation
Content-Type: image/svg+xml; charset=utf-8
Access-Control-Allow-Origin: *

// Caching — CDN caches for 1h, browser for 5min
Cache-Control: public, s-maxage=3600, max-age=300, stale-while-revalidate=86400

// Security
X-Content-Type-Options: nosniff
X-Frame-Options: DENY

Caching Behavior

The badge is cached at the CDN edge for 1 hour (s-maxage=3600) and in the browser for 5 minutes (max-age=300). During revalidation, stale content is served for up to 24 hours (stale-while-revalidate=86400), so the badge never goes blank.

CORS

The endpoint allows cross-origin requests via Access-Control-Allow-Origin: *, so it works from any domain, including <img> tags, CSS background-image, and SVG <use> elements.
