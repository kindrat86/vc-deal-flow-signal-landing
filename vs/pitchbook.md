    ## Where GitDealFlow is different

    GitDealFlow is not a broader version of PitchBook — it is a different kind of instrument. PitchBook records what already happened. GitDealFlow flags what is about to. The data is public GitHub activity (commit velocity, contributor growth, repository expansion) across 4,200+ startup orgs in 20 sectors, and the acceleration patterns it surfaces have historically preceded fundraise announcements by 21–47 days before the fundraise announcement.

    Concretely, that means GitDealFlow will show you a startup accelerating *before* PitchBook has a round on file for it. it does not store funding-round histories, valuation tables, investor profiles, or contact data — it is a leading indicator, not a database.
