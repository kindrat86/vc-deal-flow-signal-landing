    ## Where GitDealFlow is different

    GitDealFlow is not a broader version of Tracxn — it is a different kind of instrument. Tracxn records what already happened. GitDealFlow flags what is about to. The data is public GitHub activity (commit velocity, contributor growth, repository expansion) across 4,200+ startup orgs in 20 sectors, and the acceleration patterns it surfaces have historically preceded fundraise announcements by 21–47 days before the fundraise announcement.

    Concretely, that means GitDealFlow will show you a startup accelerating *before* Tracxn has a round on file for it. it does not store funding-round histories, valuation tables, investor profiles, or contact data — it is a leading indicator, not a database.

    
            - Post-round — no pre-round engineering signal

            - Coverage depth outside emerging markets is thinner than Crunchbase/PitchBook

            - Profile freshness varies by sector

    
    **Important:** Tracxn is not wrong or bad — it answers a different question. Most serious deal-flow teams run both: a database for the record, and a signal for the lead.
