Dataset Overview

The VC Deal Flow Signal Dataset tracks engineering activity across 356 startup GitHub organizations in 15 sectors. Six variables are computed weekly from public commit, contributor, and repository data. The dataset powers the signal board at signals.gitdealflow.com and is the foundation for the SSRN preprint.

Data Schema

Each row in the CSV/JSON represents one startup-week observation. The full schema is documented at OpenAPI 3.1 spec.

Field Type Description
namestringStartup name
sectorstringIndustry sector slug (e.g. fintech, healthtech)
weekstringISO week identifier (e.g. 2026-W30)
commit_velocityintegerTotal commits across all repositories in the week
contributor_countintegerUnique contributors active during the week
contributor_growthfloatWeek-over-week contributor count change (%)
repo_countintegerActive repositories with commits
repo_expansionfloatWeek-over-week active repo count change (%)
engineering_momentum_scorefloatComposite score (0–100) combining all velocity signals
is_acceleratingbooleanFlag indicating breakout acceleration (top 5% momentum gain)
star_ratingintegerInvestor star rating (1–5) based on signal strength
stagestringFunding stage estimate: seed, series-a, series-b, series-c+

Weekly Updates

The dataset is refreshed every Monday at 09:00 UTC. Each update covers engineering activity for the prior week (Sunday–Saturday). Historical data reaches back to January 2024, giving you a 2.5+ year trend baseline.

  • Monday 09:00 UTC — Data refresh & signal recomputation
  • Sunday 14:00 UTC — Weekly acceleration watch email sent to subscribers
  • Ongoing — API and CSV/JSON exports always serve the latest completed week

Frequently Asked Questions

Do I need to sign up to download the data?
No. All downloads and API access are free and require no authentication, sign-up, or API key.
How often is the dataset updated?
Every Monday at 09:00 UTC. Each update covers the prior calendar week (Sunday through Saturday).
How many startups are tracked?
356 startup GitHub organizations across 15 sectors. The coverage grows each quarter as we add new startups meeting our minimum activity threshold.
What sectors are covered?
Fintech, healthtech, AI/ML, devtools, infrastructure, cybersecurity, climate/energy, biotech, edtech, gaming, SaaS, e-commerce, robotics, space, and transportation.
Can I use this data for commercial purposes?
Yes, under CC BY 4.0. Commercial use is permitted as long as you provide attribution to GitDealFlow and a link to the SSRN preprint.
Is there an API rate limit?
The free API does not currently enforce rate limits. We reserve the right to introduce reasonable limits if usage grows beyond our infrastructure capacity. The dataset is always available via direct CSV/JSON download.
