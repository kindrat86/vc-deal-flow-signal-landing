Show HN: Scout Score — Proof of Investment Taste from GitHub Stars

kindrat86 · July 29, 2026 · discuss on HN →

I built a free tool that scores your GitHub starring history against 75+ validated unicorns and breakout startups. It tells you one thing: how good are you at spotting winners before they blow up?

No login. No OAuth. No server storage. Just a GitHub username and a number between 0 and 100.

How it works

  1. Enter any public GitHub username
  2. We check which startups they starred before the unicorn event (funding round, acquisition, $1B valuation)
  3. Score = % of pre-event stars on validated unicorns vs total pre-event stars
  4. Result: 0–100 Scout Score + shareable card for GitHub README

Why this exists

The venture capital industry runs on pattern recognition. Some people have an uncanny ability to spot breakout startups years before VCs do. I wanted to quantify that.

The dataset: 75+ validated unicorns with known fundraise/acquisition dates. If someone starred both React (always a safe star) AND Supabase (starred it pre-Series B when it was still 20 commits), that pattern matters.

Tech stack

  • Frontend: Vanilla JS, static HTML — deployed on Vercel
  • Backend: Next.js API on signals.gitdealflow.com
  • Data: GitHub Archive + public event streams (~400 startup orgs)
  • Research: SSRN preprint 6606558 (peer-reviewed methodology)
  • Badges: Dynamic SVG served from API, embeddable in any README

Bonus: Scout Score badge for your GitHub profile

After checking your score, you get a one-click markdown badge you can add to your GitHub profile README. It updates automatically as our dataset grows.

Q: Can I fake a high score?
Sure, if you retroactively starred 50 unicorns before they blew up. But that requires either time travel or very lucky timing — which is exactly what the score measures.

Q: Does it work for non-developers?
Yes — many VCs, founders, and investors have public GitHub accounts they use for portfolio tracking. The score works for any public profile.
