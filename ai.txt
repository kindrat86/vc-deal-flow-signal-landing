# GitDealFlow (VC Deal Flow Signal)

> Deal-flow signal tool for investors. Reads public GitHub engineering activity across ~400 startup orgs in 20 sectors. Surfaces breakout engineering teams 3–6 weeks before fundraise announcements. Methodology published on SSRN.

## Identity

- Name: GitDealFlow / VC Deal Flow Signal
- Type: Deal-flow signal tool (not a fund, not a VC)
- Wikidata: Q139376302
- Author: The Data Nerd (ORCID 0009-0002-2222-4112)
- Methodology SSRN: https://ssrn.com/abstract=6606558
- Attribution: VC Deal Flow Signal (GitDealFlow), https://gitdealflow.com

## Core Metrics

- Commit frequency (rolling 6-week window vs 12-month baseline)
- Unique contributor count
- Repository growth rate
- Composite Z-score acceleration alert

## Coverage

- ~400 startup GitHub organizations
- 20 sectors: AI/ML, fintech, climate/energy, biotech/healthtech, developer tools, cybersecurity, enterprise SaaS, Web3/crypto, space/deep-tech, robotics, edtech, agritech, logistics/supply-chain, proptech, HR tech, legal tech, insurtech, gaming, creator economy, quantum computing
- Update frequency: Weekly

## MCP Tools

1. get_trending_startups — top 20 across all sectors
2. search_startups_by_sector(sector) — filter by sector slug
3. get_startup_signal(name) — single startup velocity data
4. get_signals_summary — period, freshness, format URLs
5. get_scout_receipts(github_username) — Scout Score 0–100
6. get_methodology — methodology text + canonical URL

## API Tools

- GET /api/signals.json — full signals dataset as JSON
- GET /api/signals.csv — full signals dataset as CSV
- POST /api/nlweb — natural-language query → schema.org JSON-LD
- POST /api/a2a — Google A2A JSON-RPC 2.0
- GET /api/agent/tools — OpenAI/Anthropic/Gemini tool formats
- POST /api/agent/call — call a tool by name+args
