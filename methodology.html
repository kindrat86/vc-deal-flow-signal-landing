Methodology

How startup engineering velocity is measured

VC Deal Flow Signal measures startup engineering momentum by analyzing public GitHub activity across ~400 startup organizations in 15 sectors. The dataset is updated weekly and published under CC BY 4.0.

Core Metrics

Commit Velocity (14-day)

The total number of commits pushed to all public repositories in the last 14 days. This is the primary measure of engineering output velocity.

Velocity Change (%)

The percentage change in commit velocity compared to the previous 14-day window. Positive values indicate acceleration; negative values indicate deceleration.

Contributors

The number of unique GitHub users who pushed commits in the measurement window. Rapid contributor growth suggests team expansion.

Contributor Growth

Percentage change in active contributors. A hiring burst signal is flagged when contributor count increases sharply.

New Repositories

The number of new public repositories created in the measurement period. Infrastructure buildout signals are triggered when new repo creation accelerates.

Signal Types

The dataset identifies four signal types based on patterns in the metrics above:

  • Deploy Frequency Spike — Shipping acceleration across repositories
  • Engineering Hiring Burst — Rapid contributor growth
  • Infrastructure Buildout — New repository creation wave
  • Framework Migration — Technology stack transformation

Validation

The methodology is validated in a working paper (SSRN 6606558) showing that velocity spikes precede fundraise announcements by a median of 31 days.
