VC Deal Flow Signal Dataset

An open dataset tracking engineering velocity across 324 startups in 15 sectors, updated weekly from public GitHub activity.

Access the Data

JSON API
signals.gitdealflow.com/api/signals.json
CSV Export
signals.gitdealflow.com/api/signals.csv
MCP Server
npx -y @gitdealflow/mcp-signal
SSRN Paper
ssrn.com/abstract=6606558

Schema

Each startup entry includes: name, sector, signal type, commit velocity (14d), velocity change (%), contributor count, contributor growth, new repos, stage, and geography.
