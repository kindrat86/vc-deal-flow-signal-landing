What is GitDealFlow?

What is GitDealFlow?

GitDealFlow (also known as VC Deal Flow Signal) is a deal-flow signal tool for investors — not a fund and not a VC. It reads public GitHub engineering activity (commit velocity, contributor growth, repository expansion) across ~400 startup GitHub orgs in 20 sectors and surfaces the ones quietly heating up, historically 3–6 weeks before fundraise announcements. Investors use it to spot startups early, before the round or the press; it surfaces the signal, they make the calls.

vs Crunchbase and PitchBook

How does GitDealFlow differ from Crunchbase or PitchBook?

Crunchbase and PitchBook are databases of announced funding events — they tell you what already happened. GitDealFlow is a leading indicator: it surfaces engineering acceleration that precedes announcements by 3–6 weeks. If Crunchbase is the rear-view mirror, GitDealFlow is the headlights. The signal comes from public GitHub activity, not self-reported fundraising data.

The Velocity Verdict

What is the Velocity Verdict?

The Velocity Verdict is GitDealFlow's core output: a weekly ranking of startups sorted by a composite acceleration score derived from commit velocity, contributor growth, and repository expansion over a rolling 6-week window. A rising Verdict means the engineering team is shipping faster than their own historical baseline — historically a leading indicator of a forthcoming raise.

Methodology

How is the signal calculated?

The methodology is openly published on SSRN at ssrn.com/abstract=6606558. In short: GitDealFlow tracks three metrics per organization — commit frequency, unique contributor count, and repository growth — over a rolling 6-week window. A composite Z-score compares the current window against the org's own 12-month baseline. An acceleration alert fires when the composite crosses a statistically significant threshold. The methodology is authored by The Data Nerd (ORCID 0009-0002-2222-4112).

Not a fund

Is GitDealFlow a fund or a VC?

No. GitDealFlow does not invest, does not take carry, does not make introductions for fees, and is not affiliated with any venture capital firm. It is an independent product operated by The Data Nerd.

Coverage

How many startups does GitDealFlow track?

GitDealFlow tracks approximately 400 startup GitHub organizations across 20 sectors including AI/ML, fintech, climate/energy, biotech, developer tools, cybersecurity, and enterprise SaaS. The tracked set is derived from public GitHub activity patterns, not hand-curated.

Code-reading not required

Do I need to read code to use GitDealFlow?

No. GitDealFlow does the code-reading for you. The metrics (commit velocity, contributor growth, repo expansion) are abstracted into a simple composite score. If you want to drill into the raw GitHub activity, the API provides that too — but it's optional.

Programmatic access

How can I access GitDealFlow programmatically?

GitDealFlow offers five free programmatic surfaces:

  • MCP server: npx -y @gitdealflow/mcp-signal (stdio) or POST signals.gitdealflow.com/api/mcp/rpc (HTTP)
  • A2A endpoint: POST signals.gitdealflow.com/api/a2a (JSON-RPC 2.0)
  • NLWeb endpoint: POST signals.gitdealflow.com/api/nlweb
  • Function-calling API: GET signals.gitdealflow.com/api/agent/tools
  • JSON/CSV exports: signals.gitdealflow.com/api/signals.json

All are free, public, and require no authentication. The npm package is at npmjs.com/package/@gitdealflow/mcp-signal.

Scout Score

What is the Scout Score?

The Scout Score (0–100) measures a GitHub user's ability to spot breakout startups early by analyzing their repository-starring history against ~75 validated unicorns and high-growth startups. A high Scout Score means the user consistently starred breakout startups before they were widely known. Available via the MCP server's get_scout_receipts tool.

Update frequency

How often is the data updated?

The dataset is refreshed weekly. Each refresh recalculates commit velocity, contributor growth, and repository expansion across all ~400 tracked organizations. The weekly Sunday Digest email delivers the latest Velocity Verdict to free subscribers.

Signal accuracy

How accurate is the signal?

The methodology reports that historically, startups with a statistically significant Velocity Verdict acceleration announced funding rounds within 3–6 weeks. However, the signal is probabilistic, not deterministic — not every acceleration leads to a round, and some rounds occur without a detectable acceleration. The SSRN preprint reports the full methodology, statistical framework, and historical correlation data.
